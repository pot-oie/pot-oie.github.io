# Series Progress Indexes

This directory stores retrieval-oriented progress notes for published blog series.

These files are not public-facing articles. They are meant to help future Codex sessions quickly align with what has already been written, what concepts have been covered, and where new topics should fit.

Naming convention:

- Use the content `series.key` as the file name when possible.
- Keep one Markdown file per major series.
- Include only published posts by default (`draft: false`), and list drafts separately as follow-up material.

Current indexes:

- `machine-learning.md`: ML-to-LLM learning route, from classical ML through DL, CNN/RNN/GNN, Transformer, LLM, Diffusion, and DiT.
